# MD5Gen для Dev-C++

GUI-приложение на C++11 и WinAPI для Windows 7 и новее. Вычисляет MD5 содержимого файлов через Windows CryptoAPI, читая данные блоками по 64 КиБ. Внешние библиотеки не требуются.

## Запуск

Запустите `MD5Gen.exe`. Рядом с программой находится `config.json` со списком полных путей. Если файла настроек нет, программа создаст его. Каталог программы должен быть доступен для записи.

1. Нажмите **Добавить файлы…**. Можно выбрать несколько файлов с Ctrl или Shift.
2. Для удаления путей выделите строки (Ctrl/Shift) и нажмите **Удалить выбранные**. Сами файлы не удаляются.
3. При необходимости включите **Сохранить результат в файл**.
4. Нажмите **Сгенерировать MD5**. Если включено сохранение, выберите имя отчёта.
5. Результаты появятся в отдельной консоли. Кнопка **Показать консоль** возвращает её на экран.

Добавление и удаление автоматически сохраняют настройки. Повторные пути не добавляются. Расчёт идёт в отдельном потоке; изменение списка и закрытие главного окна доступны после его завершения. Консоль закрывается вместе с главным окном.

Формат строк отчёта — имя файла, табуляция, MD5 из 32 шестнадцатеричных символов:

```text
abc.txt	900150983cd24fb0d6963f7d28e17f72
empty.txt	d41d8cd98f00b204e9800998ecf8427e
```

Текстовый отчёт сохраняется в UTF-8. Если файл недоступен, вместо MD5 выводится `ОШИБКА: ...`, остальные файлы продолжают обрабатываться. Файлы с одинаковыми именами из разных каталогов дают отдельные строки в порядке списка. В отчёте используются именно имена, без каталогов.

## Сборка в Dev-C++

1. Откройте проект `MD5Gen.dev` через **Файл → Открыть проект или файл**.
2. Выберите установленный компилятор MinGW/TDM-GCC с поддержкой C++11.
3. Выполните **Выполнить → Перекомпилировать всё**, затем **Запустить**.

Проект имеет тип Windows GUI. Параметры C++: `-std=c++11 -Wall -Wextra -O2 -finput-charset=UTF-8 -fexec-charset=UTF-8`. Библиотеки линковки: `advapi32`, `comdlg32`, `gdi32`, `user32`. Исходники сохранены в UTF-8.

Альтернативная сборка: запустите `build.bat`. Он автоматически использует стандартную установку Embarcadero Dev-C++ или `g++.exe` из PATH. Можно передать собственный путь:

```bat
build.bat "C:\Dev-Cpp\MinGW64\bin\g++.exe"
```

Готовый `MD5Gen.exe` создаётся в каталоге проекта. Для переноса достаточно EXE и, при необходимости, `config.json`.

## Настройки JSON

```json
{
  "files": [
    "C:\\Data\\document.pdf",
    "D:\\Проекты\\firmware.bin",
    "\\\\server\\share\\archive.zip"
  ]
}
```

В JSON обратные слеши удваиваются; допустима также запись `C:/Data/document.pdf`. Кириллица поддерживается напрямую в UTF-8 и через escape-последовательности `\uXXXX`. Поддерживаются абсолютные пути с буквой диска и UNC. Настройки содержат только поле `files` — массив строк. Правьте JSON при закрытой программе: он загружается при запуске.

Некорректный JSON вызывает сообщение об ошибке запуска; исходный файл не перезаписывается. Отсутствующие файлы остаются в списке и сообщают об ошибке при расчёте. Настройки и отчёт записываются через временный файл с последующей заменой, чтобы не оставить частично записанный результат. Отчётом нельзя перезаписать `config.json` или один из обрабатываемых файлов.

## Проверки

`test.bat` собирает и запускает тесты: известные MD5 для пустого файла, `abc`, `message digest`, миллиона символов `a` и бинарных данных; Unicode/UNC; чтение и запись JSON; повреждённый JSON; недоступные файлы; сохранность настроек при неудачной записи. Временные данные тестов находятся в `tests/tmp`.

Проверено компилятором TDM-GCC 9.2.0 из установленного Embarcadero Dev-C++.
